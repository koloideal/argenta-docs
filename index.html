1. Введение

Argenta — это современная Python-библиотека для разработки текстовых CLI интерфейсов`. Библиотека предоставляет простой и элегантный способ создания интерактивных консольных приложений с богатым функционалом, включая автодополнение команд, обработку флагов и аргументов, пользовательские обработчики ошибок и многое другое.

Основная цель Argenta — упростить процесс создания сложных консольных интерфейсов, предоставляя модульную архитектуру и интуитивно понятный API. Библиотека отлично подходит для создания CLI-утилит, административных интерфейсов и других приложений, требующих взаимодействия через терминал.

Ключевые особенности:

  • Декларативное определение команд и обработчиков
  • Поддержка вложенных команд и маршрутизаторов
  • Автодополнение команд и историю ввода
  • Гибкая система обработки флагов и аргументов
  • Пользовательские обработчики ошибок
  • Модульная архитектура для легкого расширения
  • Настраиваемый внешний вид и поведение

2. Установка

Установка Argenta производится с помощью менеджера пакетов pip: 

pip install argenta

Или с помощью Poetry: 

poetry add argenta

Библиотека совместима с Python 3.8 и выше.

3. Быстрый старт

Ниже приведены примеры создания простых CLI-приложений с использованием Argenta.

Пример 1: Простейшее приложение с одной командой

Создадим минимальное приложение с одной командой hello, которая выводит сообщение "Hello, world!".

routers.py:

from argenta.router import Router
from argenta.command import Command
from argenta.response import Response

router = Router()

@router.command(Command("hello"))
def handler(response: Response):
  print("Hello, world!")

main.py:

from argenta.app import App
from argenta.orchestrator import Orchestrator
from routers import router

app: App = App()
orchestrator: Orchestrator = Orchestrator()

def main() -> None:
    app.include_router(router)
    orchestrator.start_polling(app)

if __name__ == '__main__':
    main()

Пример 2: TUI с обработкой флагов

Создадим приложение с командой ssh, которая обрабатывает флаги --host и --port. 

import re
from argenta.router import Router
from argenta.command import Command
from argenta.response import Response
from argenta.orchestrator import Orchestrator
from argenta.command.flag.defaults import PredefinedFlags
from argenta.command.flag import Flags, Flag, InputFlags

router = Router()

registered_flags = Flags(PredefinedFlags.HOST,
                        Flag('port', '--', re.compile(r'^[0-9]{1,4}$')))

@router.command(Command("hello"))
def handler(response: Response):
    print("Hello, world!")

@router.command(Command(trigger="ssh",
                       description='connect via ssh',
                       flags=registered_flags))
def handler_with_flags(response: Response):
    for flag in response.valid_flags:
        print(f'Flag name: {flag.get_name()}\n'
              f'Flag value: {flag.get_value()}')

После запуска этого приложения вы сможете вводить команды вида: 

ssh --host 192.168.1.10 --port 22

И ваш обработчик получит эти флаги и их значения для дальнейшей обработки.

4. Архитектура

Библиотека Argenta построена на модульной архитектуре, которая обеспечивает гибкость и расширяемость. Ниже приведена схема взаимодействия основных компонентов:

Основные компоненты:

  • App - основной класс приложения, управляющий жизненным циклом и поведением TUI. Отвечает за регистрацию маршрутизаторов и обработку системных событий.
  • Router - маршрутизатор, регистрирующий обработчики команд. Каждый Router может содержать множество команд и их обработчиков.
  • Command - модель команды, которая содержит триггер (строку для активации), описание и допустимые флаги.
  • Flags - система для определения и обработки флагов командной строки.
  • InputFlags - контейнер для хранения флагов, введенных пользователем.
  • Orchestrator - оркестратор приложения, управляющий циклом обработки ввода и направляющий команды в соответствующие обработчики.
  • ArgParse - парсер аргументов командной строки при запуске приложения.
  • AutoCompleter - компонент для автодополнения команд.

Поток выполнения

  1. Создание экземпляра App и настройка его параметров
  2. Регистрация маршрутизаторов (Router) в приложении через app.include_router()
  3. Запуск цикла обработки ввода через orchestrator.start_polling(app)
  4. Пользователь вводит команду
  5. Orchestrator анализирует ввод и определяет соответствующий обработчик
  6. Если команда найдена, выполняется соответствующий обработчик
  7. Если возникают ошибки ввода, вызываются соответствующие обработчики ошибок
  8. Цикл повторяется, пока не будет введена команда выхода

5.3 Command (Команда)

Command — это класс, представляющий команду, которая может и должна быть зарегистрирована в Router. Определяет триггер, описание, флаги и псевдонимы команды.

Конструктор

def __init__(trigger: str, description: str = None, flags: Flag | Flags = None, aliases: list[str] = None)

Параметры:

  • trigger - строка-триггер, которая при вводе пользователем указывает, что ввод соответствует команде
  • description - описание команды
  • flags - обрабатываемые флаги
  • aliases - строковые синонимы для основного триггера

Пример использования:

from argenta.command import Command
from argenta.command.flag import Flag, Flags
import re

# Простая команда без флагов
simple_command = Command("hello", "Приветственная команда")

# Команда с одним флагом
flag_command = Command(
    trigger="search",
    description="Поиск по ключевому слову",
    flags=Flag("keyword", "--")
)

# Команда с несколькими флагами и псевдонимами
complex_command = Command(
    trigger="connect",
    description="Подключение к серверу",
    flags=Flags(
        Flag("host", "--"),
        Flag("port", "--", re.compile(r"^\d{1,5}$")),
        Flag("user", "--")
    ),
    aliases=["conn", "c"]
)

PredefinedFlags

Класс PredefinedFlags — это датакласс с предопределенными флагами и наиболее часто используемыми флагами для быстрого использования.

Пример использования:

import re
from argenta.command.flag import Flag, Flags, InputFlags
from argenta.command.flag.defaults import PredefinedFlags

# Создание флага без значения (булев флаг)
verbose_flag = Flag('verbose', '--', False)

# Создание флага со значением из списка
log_level_flag = Flag('log-level', '--', ['debug', 'info', 'warning', 'error'])

# Создание флага со значением, соответствующим регулярному выражению
port_flag = Flag('port', '--', re.compile(r'^\d{1,5}$'))

# Использование предопределенных флагов
host_flag = PredefinedFlags.HOST

# Создание группы флагов
connection_flags = Flags(
    host_flag,
    port_flag,
    Flag('user', '--'),
    Flag('password', '--')
)

# Обработка входных флагов в обработчике команды
@router.command(Command("connect", "Подключение к серверу", flags=connection_flags))
def connect_handler(flags: InputFlags):
    host = flags.get_flag('host').get_value()
    port = flags.get_flag('port').get_value() if flags.get_flag('port') else '22'
    user = flags.get_flag('user').get_value() if flags.get_flag('user') else 'root'

    print(f"Подключение к {host}:{port} как {user}")

5.5 Orchestrator (Оркестратор)

Orchestrator — это класс, который определяет поведение интегрированной системы, на уровень выше, чем App. Он управляет циклом обработки ввода и направляет команды в соответствующие обработчики.

def __init__(arg_parser: ArgParse = False)

  • arg_parser - парсер и конфигуратор аргументов командной строки при запуске

Основные методы

start_polling

Запуск цикла обработки пользовательского ввода.

Параметры:

  • app - запускаемое приложение
get_input_args
def get_input_args() -> Namespace | None

Возвращает разобранные аргументы.

Возвращает:

  • Разобранные аргументы или None

Пример использования:

from argenta.app import App
from argenta.orchestrator import Orchestrator
from argenta.orchestrator.argparser import ArgParse
from argenta.orchestrator.argparse.arguments import OptionalArgument, BooleanArgument

# Создание парсера аргументов командной строки
arg_parser = ArgParse(
    [
        OptionalArgument('config', prefix='--'),
        BooleanArgument('verbose', prefix='--')
    ],
    name="Мое приложение",
    description="Описание моего приложения",
    epilog="© 2025 MyApp"
)

# Создание оркестратора с парсером аргументов
orchestrator = Orchestrator(arg_parser)

# Создание и настройка приложения
app = App(initial_message="Добро пожаловать!")

# Запуск цикла обработки ввода
orchestrator.start_polling(app)

# Получение аргументов командной строки
args = orchestrator.get_input_args()
if args and args.verbose:
    print("Включен подробный режим логирования")

5.6 ArgParse (Парсер аргументов)

ArgParse — это класс для разбора и конфигурации аргументов командной строки при запуске.

Конструктор

Параметры:

  • processed_args - зарегистрированные и обрабатываемые аргументы
  • name - имя экземпляра ArgParse
  • description - описание экземпляра ArgParse
  • epilog - эпилог экземпляра ArgParse

Основные методы

set_args
def set_args(*args: PositionalArgument | OptionalArgument | BooleanArgument) -> None

Устанавливает аргументы для обработки.

Параметры:

  • args - обрабатываемые аргументы

Типы аргументов

PositionalArgument

Обязательный аргумент при запуске.

def __init__(name: str)

Параметры:

  • name - имя аргумента, не должно начинаться с минуса (-)
OptionalArgument

Необязательный аргумент, должен иметь значение.

def __init__(name: str, prefix: Literal['-', '--', '---'] = '--')

Параметры:

  • name - имя аргумента
  • prefix - префикс аргумента
BooleanArgument

Булевый аргумент, не требует значения.

def __init__(name: str, prefix: Literal['-', '--', '---'] = '--')

Параметры:

  • name - имя аргумента
  • prefix - префикс аргумента

Пример использования:

from argenta.orchestrator.argparser import ArgParse
from argenta.orchestrator.argparse.arguments import PositionalArgument, OptionalArgument, BooleanArgument

# Создание парсера аргументов с разными типами аргументов
parser = ArgParse(
    [
        PositionalArgument('command'),
        OptionalArgument('config', '--'),
        OptionalArgument('output', '-'),
        BooleanArgument('verbose', '--'),
        BooleanArgument('help', '-')
    ],
    name="Мое приложение",
    description="Пример использования ArgParse",
    epilog="Дополнительная информация"
)

# Добавление дополнительных аргументов
parser.set_args(
    OptionalArgument('log-level', '--'),
    BooleanArgument('quiet', '-')
)

Конструктор

def __init__(history_filename: str = False, autocomplete_button: str = 'tab') -> None

Параметры:

  • history_filename - имя файла для сохранения истории автодополнителя
  • autocomplete_button - кнопка для автодополнения

from argenta.app import App

5.8 DividingLine (Разделительная линия)

Библиотека предоставляет два типа разделительных линий: StaticDividingLine и DynamicDividingLine.

StaticDividingLine

Статическая разделительная линия с фиксированной длиной.

def __init__(unit_part: str = '-', length: int = 25) -> None

Параметры:

  • unit_part - одиночная часть разделительной линии
  • length - длина разделительной линии
get_full_static_line

Возвращает полную статическую линию.

DynamicDividingLine

Динамическая разделительная линия, длина которой зависит от ширины терминала.

def __init__(unit_part: str = '-') -> None

Параметры:

  • unit_part - одиночная часть разделительной линии
get_full_dynamic_line

Возвращает полную динамическую линию.

Пример использования:

from argenta.app import App
from argenta.app.dividing_line import StaticDividingLine, DynamicDividingLine

# Использование статической разделительной линии
app_with_static_line = App(
    dividing_line=StaticDividingLine(unit_part='=', length=40)
)

# Использование динамической разделительной линии
app_with_dynamic_line = App(
    dividing_line=DynamicDividingLine(unit_part='*')
)

6.1 Маршрутизатор с обработкой флагов

Пример реализации маршрутизатора с командами, которые обрабатывают различные типы флагов. 

import re
from argenta.router import Router
from argenta.command import Command
from argenta.command.flag import Flag, Flags, InputFlags
from argenta.command.flag.defaults import PredefinedFlags

# Создание маршрутизатора
file_router = Router("Операции с файлами")

# Определение флагов для команды копирования
copy_flags = Flags(
    Flag('source', '--'),
    Flag('destination', '--'),
    Flag('recursive', '--', False),  # Булевый флаг без значения
    Flag('force', '-', False)        # Короткий булевый флаг
)

# Определение флагов для команды поиска
search_flags = Flags(
    Flag('path', '--'),
    Flag('pattern', '--'),
    Flag('case-sensitive', '--', False),
    Flag('max-depth', '--', re.compile(r'^\d+$'))  # Значение только числовое
)

# Регистрация команды копирования
@file_router.command(Command(
    trigger="copy",
    description="Копирование файлов",
    flags=copy_flags,
    aliases=["cp"]
))
def copy_files(flags: InputFlags):
    source = flags.get_flag('source').get_value()
    destination = flags.get_flag('destination').get_value()
    recursive = flags.get_flag('recursive') is not None
    force = flags.get_flag('force') is not None

    print(f"Копирование из {source} в {destination}")
    if recursive:
        print("Рекурсивное копирование включено")
    if force:
        print("Принудительное копирование включено")

# Регистрация команды поиска
@file_router.command(Command(
    trigger="search",
    description="Поиск файлов",
    flags=search_flags,
    aliases=["find"]
))
def search_files(flags: InputFlags):
    path = flags.get_flag('path').get_value() if flags.get_flag('path') else "."
    pattern = flags.get_flag('pattern').get_value() if flags.get_flag('pattern') else "*"
    case_sensitive = flags.get_flag('case-sensitive') is not None
    max_depth = flags.get_flag('max-depth').get_value() if flags.get_flag('max-depth') else None

    print(f"Поиск файлов по шаблону '{pattern}' в директории '{path}'")
    if case_sensitive:
        print("Поиск с учетом регистра")
    if max_depth:
        print(f"Максимальная глубина поиска: {max_depth}")

# Обработка неверных флагов
@file_router.set_invalid_input_flag_handler
def handle_invalid_flag(flag_name: str):
    print(f"Ошибка: неизвестный флаг '{flag_name}'")

Чтобы использовать этот маршрутизатор, включите его в приложение и запустите с помощью оркестратора: 

from argenta.app import App
from argenta.orchestrator import Orchestrator

app = App(
    prompt="File Manager> ",
    initial_message="Файловый менеджер v1.0"
)
app.include_router(file_router)

orchestrator = Orchestrator()
orchestrator.start_polling(app)

Пример команд, которые можно использовать: 

copy --source /path/to/source --destination /path/to/destination --recursive -f
search --path /home/user --pattern "*.py" --case-sensitive --max-depth 3

6.2 Множественные маршрутизаторы

Пример приложения с несколькими маршрутизаторами для различных групп функций. 

from argenta.app import App
from argenta.router import Router
from argenta.command import Command
from argenta.orchestrator import Orchestrator
from argenta.app.dividing_line import DynamicDividingLine

# Маршрутизатор для работы с файлами
file_router = Router("Файловые операции")

@file_router.command(Command("list", "Список файлов"))
def list_files():
    import os
    files = os.listdir()
    for file in files:
        print(file)

@file_router.command(Command("size", "Размер файла"))
def file_size():
    import os
    file_name = input("Введите имя файла: ")
    if os.path.exists(file_name):
        size = os.path.getsize(file_name)
        print(f"Размер файла {file_name}: {size} байт")
    else:
        print(f"Файл {file_name} не найден")

# Маршрутизатор для системных операций
system_router = Router("Системные операции")

@system_router.command(Command("info", "Информация о системе"))
def system_info():
    import platform
    print(f"Система: {platform.system()}")
    print(f"Версия: {platform.version()}")
    print(f"Архитектура: {platform.architecture()}")
    print(f"Процессор: {platform.processor()}")

@system_router.command(Command("memory", "Информация о памяти"))
def memory_info():
    import psutil
    memory = psutil.virtual_memory()
    print(f"Всего памяти: {memory.total / (1024**3):.2f} ГБ")
    print(f"Доступно: {memory.available / (1024**3):.2f} ГБ")
    print(f"Использовано: {memory.used / (1024**3):.2f} ГБ ({memory.percent}%)")

# Маршрутизатор для сетевых операций
network_router = Router("Сетевые операции")

@network_router.command(Command("ping", "Проверка доступности хоста"))
def ping_host():
    import subprocess
    host = input("Введите имя хоста: ")
    print(f"Пингую {host}...")
    subprocess.run(["ping", "-c", "4", host])

@network_router.command(Command("ip", "Показать IP-адреса"))
def show_ip():
    import socket
    hostname = socket.gethostname()
    print(f"Имя хоста: {hostname}")
    print(f"IP-адрес: {socket.gethostbyname(hostname)}")

# Создание приложения и регистрация маршрутизаторов
app = App(
    prompt="System> ",
    initial_message="Системный монитор v1.0",
    dividing_line=DynamicDividingLine("*")
)

# Добавляем все маршрутизаторы
app.include_routers(file_router, system_router, network_router)

# Добавляем сообщение при запуске
app.add_message_on_startup("Для просмотра доступных команд нажмите Enter")

# Запускаем приложение
orchestrator = Orchestrator()
orchestrator.start_polling(app)

6.3 Пользовательские обработчики ошибок

Пример приложения с пользовательскими обработчиками ошибок для улучшения отзывчивости пользовательского интерфейса. 

from argenta.app import App
from argenta.router import Router
from argenta.command import Command
from argenta.orchestrator import Orchestrator
from rich.console import Console
from rich.panel import Panel
from rich.text import Text

# Создаем консоль Rich для более красивого вывода
console = Console()

# Создаем маршрутизатор
router = Router("Основные команды")

@router.command(Command("hello", "Приветствие"))
def hello():
    console.print(Panel("Привет, мир!", style="green"))

@router.command(Command("bye", "Прощание"))
def bye():
    console.print(Panel("До свидания!", style="blue"))

# Создаем приложение
app = App(
    prompt="MyApp> ",
    initial_message="Тестовое приложение v1.0",
    print_func=console.print
)

# Регистрируем маршрутизатор
app.include_router(router)

# Пользовательский обработчик неизвестных команд
def unknown_command_handler(cmd: str):
    text = Text()
    text.append("Неизвестная команда: ", style="bold red")
    text.append(cmd, style="italic")
    text.append("\nДоступные команды: hello, bye, Q (выход)")
    console.print(Panel(text, title="Ошибка", border_style="red"))

# Пользовательский обработчик пустых команд
def empty_command_handler():
    console.print(Panel("Для выхода введите Q", style="yellow"))

# Пользовательский обработчик неверных флагов
def invalid_flag_handler(flag: str):
    console.print(Panel(f"Неизвестный флаг: {flag}", title="Ошибка", style="red"))

# Пользовательский обработчик повторяющихся флагов
def repeated_flag_handler(flag: str):
    console.print(Panel(f"Флаг указан повторно: {flag}", title="Предупреждение", style="yellow"))

# Пользовательский обработчик выхода
def exit_handler():
    console.print(Panel("Выход из приложения...", style="blue", title="До свидания"))

# Устанавливаем обработчики в приложение
app.set_unknown_command_handler(unknown_command_handler)
app.set_empty_command_handler(empty_command_handler)
app.set_invalid_input_flags_handler(invalid_flag_handler)
app.set_repeated_input_flags_handler(repeated_flag_handler)
app.set_exit_command_handler(exit_handler)

# Запускаем приложение
orchestrator = Orchestrator()
orchestrator.start_polling(app)

7. Исключения

Библиотека Argenta предоставляет набор исключений для обработки различных ситуаций ошибок. Ниже приведен список основных исключений и их назначение:

Исключение Описание
NoRegisteredHandlersException У маршрутизатора нет зарегистрированных обработчиков
UnprocessedInputFlagException Обнаружен необработанный входной флаг
RepeatedInputFlagsException Обнаружены повторяющиеся входные флаги
EmptyInputCommandException Обнаружена пустая входная команда
RepeatedFlagNameException Зарегистрировано повторяющееся имя флага
TooManyTransferredArgsException Передано слишком много аргументов
RequiredArgumentNotPassedException Не передан обязательный аргумент
IncorrectNumberOfHandlerArgsException Передано неверное количество аргументов обработчику
TriggerContainSpacesException В регистрируемом триггере содержатся пробелы

Примечание:

Эти исключения обычно обрабатываются внутренне библиотекой Argenta, но вы можете также перехватывать их для реализации собственной логики обработки ошибок.

8. Лучшие практики

Ниже приведены рекомендации и лучшие практики для эффективного использования библиотеки Argenta:

Структура проекта

  • Размещайте маршрутизаторы в отдельных модулях для лучшей организации кода
  • Группируйте связанные команды в одном маршрутизаторе
  • Используйте осмысленные названия для команд и флагов
  • Всегда добавляйте описания к командам для самодокументирования

Обработка флагов

  • Используйте регулярные выражения для проверки значений флагов
  • Применяйте класс PredefinedFlags для стандартных флагов
  • Устанавливайте обработчики для ошибок флагов для улучшения отзывчивости
  • Проверяйте наличие флага перед обращением к его значению: 
    if flags.get_flag('optional') is not None:

Пользовательский интерфейс

  • Предоставляйте понятные сообщения об ошибках
  • Используйте DynamicDividingLine для адаптации к размеру терминала
  • Добавьте команду помощи для отображения подробной информации о командах
  • Настройте автодополнение для повышения удобства использования
  • Используйте внешние библиотеки, такие как rich, для улучшения вывода

Производительность и масштабируемость

  • Избегайте блокирующих операций в обработчиках команд
  • Для длительных операций показывайте индикатор прогресса
  • Разделяйте логику бизнес-уровня и представления
  • Используйте множественные маршрутизаторы для организации большого количества команд

Тестирование

  • Создавайте модульные тесты для обработчиков команд
  • Используйте моки для имитации пользовательского ввода
  • Тестируйте ошибочные сценарии и граничные условия
  • Создавайте тестовые кейсы для проверки регистрации команд и маршрутизаторов

9. Тестирование

Библиотека Argenta включает набор тестов для проверки функциональности. Вы можете запустить тесты следующим образом: 

python -m unittest discover

Для более подробного вывода результатов тестирования используйте флаг -v: 

python -m unittest discover -v

При разработке собственных приложений на основе Argenta рекомендуется создавать модульные тесты для проверки функциональности ваших обработчиков команд и общей логики приложения.

Пример модульного теста:

import unittest
from unittest.mock import patch
from argenta.router import Router
from argenta.command import Command
from argenta.command.flag import InputFlags, InputFlag

# Маршрутизатор для тестирования
router = Router()

@router.command(Command("test"))
def test_handler():
    return "Success"

@router.command(Command("echo"))
def echo_handler(message: str):
    return f"Echo: {message}"

@router.command(Command("flag_test"))
def flag_test_handler(flags: InputFlags):
    if flags.get_flag('verbose'):
        return "Verbose mode"
    return "Normal mode"

class TestRouterHandlers(unittest.TestCase):
    def test_simple_handler(self):
        # Проверка простого обработчика
        result = test_handler()
        self.assertEqual(result, "Success")

    def test_parameter_handler(self):
        # Проверка обработчика с параметром
        result = echo_handler("Hello")
        self.assertEqual(result, "Echo: Hello")

    def test_flag_handler_normal(self):
        # Проверка обработчика с флагами (обычный режим)
        flags = InputFlags()
        result = flag_test_handler(flags)
        self.assertEqual(result, "Normal mode")

    def test_flag_handler_verbose(self):
        # Проверка обработчика с флагами (подробный режим)
        flags = InputFlags(InputFlag("verbose", "--"))
        result = flag_test_handler(flags)
        self.assertEqual(result, "Verbose mode")

if __name__ == '__main__':
    unittest.main()
